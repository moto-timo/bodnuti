**review:** With a `[review]` table in `watch.toml`, `bodnuti poll` sends each checked patch, with context gathered in the check container, to an OpenAI-compatible endpoint serving an open-weight model, and keeps the validated findings apart from the checks' results. With escalation_model set, a patch that touches classes, meta/lib/oe or bitbake.conf, fixes a CVE, or gets a low-confidence review goes to a larger model that may read the tree through read-only git tools (draft). Each poll then scores the reviews against what the lists decided: findings near lines a later revision changed, or in files a later Fixes: commit changed, count as confirmed, by month and configuration in state/review/outcomes/ (draft). `max_tokens` in `[review]` gives a local model that reasons at length more room to answer.
